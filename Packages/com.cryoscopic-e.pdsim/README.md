# PDSim: Planning Domain Simulation

PDSim is a Unity-based framework for visualizing and authoring automated plans.

## Documentation

- [Animation API](Documentation~/ANIMATION_API.md): Guide for creating custom visualizers.
- [Animations Overview](Documentation~/ANIMATIONS.md): Detailed explanation of the animation system.
- [**NEW: Interactive Sensing & Authoring**](Documentation~/INTERACTIVE_SENSING.md): Guide for building reactive worlds using Unity physics and the Natural DSL.

## Installation

This package is designed to be used within the PDSim Unity project. Ensure the `GeTPlan` libraries are built and present in the `Plugins` folder.
